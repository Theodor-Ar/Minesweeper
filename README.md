# Сапёр

Игра «Сапёр» с графическим интерфейсом — финальный проект по практикуму (**проект 5**): поле заданного размера, случайная расстановка мин, подсчёт мин вокруг клетки, открытие клеток, «волна» открытия соседей при нуле, флаги, поражение при мине, победа когда открыты все безопасные клетки, отображение состояния поля.

## Требования

- **Python 3.9+** (рекомендуется актуальная стабильная версия)
- **Tkinter** — обычно входит в дистрибутив Python на Windows; на Linux может понадобиться пакет вроде `python3-tk`

Дополнительные зависимости из `requirements.txt` не обязательны для запуска (проект на стандартной библиотеке).

## Запуск

Из корня репозитория:

```bash
python main.py
```

Размер поля и число мин задаются в `main.py` (константы `ROWS`, `COLS`, `MINES`).

## Структура

- `main.py` — точка входа, создание окна и связка логики с интерфейсом
- `src/logic.py` — правила и состояние игры
- `src/gui.py` — отрисовка и обработка действий пользователя

## Опционально (по заданию)

Таймер, перезапуск без выхода из программы, анимации, подсказки, сохранение/загрузка — по желанию для расширения проекта.
